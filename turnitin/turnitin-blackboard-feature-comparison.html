Turnitin and Blackboard Assignment: Feature Comparison

A comparison of key features in Turnitin Feedback Studio and Blackboard Ultra Assignment Grading.

The table below compares commonly used marking, feedback and submission features across Turnitin Feedback Studio and Blackboard Ultra Assignment Grading.

Feature Turnitin Feedback Studio Blackboard Ultra Assignment Grading
In-text commenting ✅ Inline comments with bubble annotations ✅ Inline comments with bubble annotations - functionally equivalent
Comment library ✅ QuickMark comment sets - customisable and reusable ✅ Feedback comment library - customisable and reusable, with the same functionality
Multiple files ❌ Not supported ✅ Supported
Rubric integration ✅ Can link comments to rubric criteria ✅ Can link comments to rubric criteria - identical capability
Rubric grading ✅ Side-by-side rubric panel ✅ Side-by-side rubric panel with the same functionality. Blackboard rubrics also allow scale ranges for criteria, providing more flexibility in scoring within a range.
Voice/video feedback ✅ Voice comments and video feedback available ✅ Voice comments and video feedback available
Annotation tools ✅ Highlighters, strikethrough and drawing tools ✅ Highlighters, strikethrough and drawing tools - equivalent set
PDF annotation ✅ Native PDF markup ✅ Native PDF markup - equivalent
Multiple file formats ✅ Supports various formats ✅ Supports a wider range of file formats
Similarity detection ✅ Similarity Report - paid additional feature ✅ SafeAssign - included with no additional cost
Group assignments ❌ No native group assignment support ✅ Full group assignment workflow with individual or group grading options
Anonymous/blind marking ✅ Built-in anonymous marking with workflow limitations ✅ Built-in anonymous marking with workflow limitations
Multiple attempts ⚠️ Limited, awkward workflow ✅ Full support for multiple submission attempts with version tracking up to the submission deadline
Draft submissions ❌ Not supported ✅ Students can save drafts before final submission
Batch download ✅ Available with feedback ✅ Available with feedback
Accommodations ⚠️ Can set individual due dates within the Turnitin interface; less integrated with Blackboard student management ✅ Built-in exceptions for individual students, including extended due dates, additional attempts and time limits, managed directly from the gradebook or student overview
Late submission tracking ⚠️ Basic timestamp ✅ Automatic late flagging with configurable grace periods
Gradebook integration ⚠️ External sync required and can be unreliable ✅ Seamless, real-time gradebook integration
Marking workflow ⚠️ External LTI tool in a separate window or tab outside the Blackboard environment ✅ Fully integrated within the Blackboard Ultra interface
Mobile marking ⚠️ No mobile marking now possible ✅ Full mobile app marking capability
Offline marking ❌ Requires connection to Turnitin servers ✅ Can download, mark offline and re-upload

Legend

  • ✅ = Feature fully supported
  • ⚠️ = Feature partially supported or has limitations
  • ❌ = Feature not available
